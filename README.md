# AI Tool Recommendation System

## Overview
This project analyzes user preferences for AI tools and provides recommendations based on different academic tasks.

The system is built using survey data (43 responses) and presents results through a user-friendly website.

---

## Features

- Data-driven recommendations based on real user responses
- Task-specific recommendations for:
  - Content Creation
  - Proofreading
  - Image Generation
  - Information Seeking
- Shows:
  - Top 2 AI tools per task
  - Percentage preferences
  - Reasons for selection
  - User quotes/testimonials
- Direct links to AI tools

---

## Methodology

### Data Collection
- Survey conducted with 43 participants
- Questions focused on AI tool usage for academic tasks

### Data Analysis
- Quantitative analysis:
  - Percentage of tool preferences
- Content analysis:
  - Grouped user responses into categories such as:
    - Ease of use
    - Speed
    - Quality
    - Accuracy

---

## Key Findings

| Task | Recommended Tool | Reason |
|------|----------------|--------|
| Content Creation | ChatGPT | Easy to use, fast, high-quality output |
| Proofreading | Grammarly | Accurate grammar correction |
| Image Generation | Gemini | Easy to use |
| Information Seeking | ChatGPT | Fast and clear responses |
